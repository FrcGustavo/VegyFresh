# services/microsip-sync

Local persistent synchronization service using public API contracts. The order CLI reads from VegyFresh and never updates its orders or statuses. The desktop catalog importer may write only through the authorized catalog import endpoint. Do not import backend internals. Keep customer mappings, tokens and operational SQLite files local. A simulator receipt is never proof of a real Microsip order. Preserve durable intent before any external write and reconcile ambiguous outcomes before retrying. Use `make check` for lint, types, tests and build; run the TypeScript reference checks with pnpm in Docker.
